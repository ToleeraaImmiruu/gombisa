PHOTOS
======
slide-1.jpg ... slide-4.jpg  -> the home page slideshow (also used on the About, Shop, Events and Games banners)

To change a photo: replace the file and keep the same name (.jpg).
To add a slide: copy a new photo here, then add a line in frontend/src/lib/siteImages.js.

Tips
- Landscape photos around 1920 px wide look sharpest. Keep each under about 400 KB (squoosh.app).
- Only use photos you own or have permission to use, and have consent from the people shown.
- If a file is missing, the site skips it, or shows a black/red/white woven placeholder.
